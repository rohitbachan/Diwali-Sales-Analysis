# Diwali-Sales-Analysis

Project Overview
Analysis of Diwali sales data to understand **customer behavior, sales trends, and product performance using Python.

About Dataset
* 11,251 records
* Customer, product, demographic, order, and sales data
* Includes Gender, Age Group, State, Occupation, Product Category, Orders, and Amount

Tools Used
* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

Customer Analysis
Analyzed customers based on:
* Gender
* Age Group
* Marital Status
* Occupation
* State
* Zone

KPI
* Total Customers: 11,251
* Married Customers: 4,729
* Average Orders: 2.49
* Average Order Amount:₹9,452
* Total Order: 28007

Analysis Performed
* Data Cleaning
* Exploratory Data Analysis
* Customer Analysis
* Product Category Analysis
* Gender-wise Analysis
* State & Occupation Analysis

Key Insights
* Clothing & Apparel had the highest number of orders.
* Food and Electronics & Gadgets were also top categories.
* Female customers had higher orders in several major categories.
* Highest Performing Zone :Central
* Highest Performing State : Uttar Pradesh
